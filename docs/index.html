Nettoyage du Bruit

Les droits socles sont des droits présents chez la majorité des utilisateurs (ex: "Accès Réseau", "Lecteur Partagé"). Ils ne différencient pas les rôles et polluent les analyses. Cette étape les identifie automatiquement pour les isoler.
